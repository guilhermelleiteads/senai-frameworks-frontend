# 🚀 12. Deploy

## O que é Deploy?

Deploy é o processo de publicar uma aplicação para que ela fique acessível aos usuários finais pela internet. 【1-73da3f】

### Etapas

1. Compilar aplicação.
2. Configurar ambiente.
3. Executar testes finais.
4. Publicar.

# ☁️ 13. Vercel

## O que é?

Vercel é uma plataforma especializada em hospedagem e deploy de aplicações modernas. 【1-73da3f】

### Principais Recursos

### 🔗 Integração com Git

Compatível com:

- GitHub
- GitLab
- Bitbucket

### ⚡ Deploy Automático

Novo deploy a cada push realizado.

### 🌎 CDN Global

Distribuição mundial do conteúdo.

### 🔄 Rollback

Volta para versões anteriores rapidamente.

### 🔧 Serverless Functions

Execução de código backend sem gerenciar servidores.

### 📈 Escalabilidade Automática

Ajusta recursos conforme a demanda.
