O que é CSS?

CSS (Cascading Style Sheets) é utilizado para estilizar páginas web, definindo cores, fontes, layouts, alinhamentos e espaçamentos. 

body {
    background-color: #f0f0f0;
    color: #333;
}

Formas de Aplicar CSS

1. CSS Inline

<p style="color:red">
Texto Vermelho
</p>

2. CSS Interno

<style>
p{
  color: blue;
}
</style>

3. CSS Externo

<link rel="stylesheet"
href="style.css">

O que é um Framework CSS?

Um Framework CSS fornece componentes, sistema de grid, responsividade e classes prontas para acelerar o desenvolvimento web.

  • Bootstrap
  • Tailwind CSS
  • Bulma
  • Foundation
