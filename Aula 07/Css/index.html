Frameworks CSS e Estilização Web

Aprenda os conceitos fundamentais de CSS com exemplos práticos.

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem utilizada para estilizar páginas web. Com ela podemos controlar cores, fontes, margens, tamanhos e layouts.

Exemplo:

body {
    background-color: #f0f0f0;
    color: #333;
}

Formas de Aplicar CSS

1. CSS Inline

<p style="color:red;">
    Texto Vermelho
</p>

2. CSS Interno

<style>
p {
    color: blue;
}
</style>

3. CSS Externo

<link rel="stylesheet"
href="style.css">

Principais Propriedades CSS

color
background-color
border
  • color: define a cor do texto.
  • background-color: cor de fundo.
  • font-size: tamanho da fonte.
  • margin: espaço externo.
  • padding: espaço interno.
  • border: borda do elemento.
