# Resumo Geral das Aulas - Frameworks Front-end

Este documento reúne os principais conteúdos da disciplina com base nos resumos disponíveis e nos materiais e atividades registrados no repositório. Para as aulas 03 a 09, os tópicos foram sintetizados a partir dos títulos dos PDFs e dos projetos descritos no README.

## Aula 01 - Introdução a Frameworks Front-end

A disciplina apresenta os fundamentos do desenvolvimento front-end e o papel dos frameworks na criação de aplicações web modernas. O front-end reúne a interface visual, a responsividade e as interações com o usuário, além de se comunicar com serviços de back-end.

Foram introduzidos HTML, CSS e JavaScript, conceitos de UX/UI, planejamento de projetos, prototipação e frameworks como React, Angular e Vue.js. Também foram apresentados os benefícios da componentização, reutilização de código, organização e manutenção de aplicações. A atividade prática propôs criar uma aplicação com tecnologias web básicas, versioná-la no GitHub e publicá-la na Vercel.

## Aula 02 - Configuração do Ambiente de Desenvolvimento

A aula abordou ferramentas e práticas necessárias para iniciar projetos front-end: Visual Studio Code, Node.js, NPM, `package.json` e estrutura de projetos React. Também foram estudados versionamento de código, Git, branches, tags e versionamento semântico (MAJOR.MINOR.PATCH).

O conteúdo incluiu o fluxo de publicação de uma aplicação: desenvolver, versionar com Git, hospedar o código no GitHub e fazer deploy na Vercel. A atividade prática consistiu em criar uma aplicação React, publicá-la no GitHub e disponibilizá-la online.

## Aula 03 - Projetos com Frameworks Front-end

O material e o registro de atividades indicam uma prática comparativa com diferentes tecnologias: React, Vue.js, Angular e Next.js. Os projetos permitem observar diferenças de estrutura e abordagem entre bibliotecas e frameworks, além de praticar a criação e organização de aplicações.

A atividade também envolveu clonar um projeto existente usando Git. Os projetos foram mantidos em repositórios para registrar sua evolução e facilitar o compartilhamento.

## Aula 04 - Consumo de APIs no Front-end

O tema central foi integrar uma aplicação front-end a uma API. Nesse fluxo, a interface faz requisições HTTP, recebe dados do servidor e os apresenta ao usuário. O registro de atividades relaciona uma API REST publicada e uma aplicação React dedicada a consumi-la.

Essa integração conecta a camada visual aos dados e serviços do back-end. É importante tratar respostas e possíveis erros da comunicação para que a interface represente corretamente os estados da aplicação.

## Aula 05 - Criação de APIs para o Front-end

A aula complementa o consumo de APIs com a criação de serviços de back-end para atender aplicações front-end. O material está associado a projetos de API, back-end e interface, incluindo testes de requisições registrados com o Postman.

O fluxo geral envolve disponibilizar endpoints, testar as respostas da API e conectar o serviço a uma aplicação front-end. A separação entre interface e serviço facilita a organização e a evolução dos projetos.

## Aula 06 - Projetos Front-end

O material da aula tem foco em projetos front-end. No registro do repositório, a atividade correspondente aparece associada à organização de um projeto no GitHub Projects, ferramenta que permite acompanhar tarefas, responsáveis e andamento do trabalho.

O trabalho em projetos reforça a importância de organizar entregas e colaborar por meio de ferramentas de gestão e versionamento, além de aplicar os conhecimentos de desenvolvimento front-end trabalhados nas aulas anteriores.

## Aula 07 - Frameworks CSS

O tema da aula é o uso de frameworks e abordagens de CSS para construir interfaces. As atividades registradas comparam CSS escrito diretamente (Vanilla CSS) e Tailwind CSS, permitindo praticar a estilização e a organização visual de páginas.

Frameworks CSS e abordagens utilitárias podem acelerar a construção de interfaces e padronizar estilos. A escolha deve considerar as necessidades do projeto e a clareza e manutenção do código.

## Aula 08 - Projeto React

O material dá continuidade à aplicação prática de React por meio de um projeto. O registro de atividades associa as aulas 08 e 09 a uma aplicação de gestão de atividades, desenvolvida com React e publicada para acesso online.

O projeto reúne a organização de uma aplicação front-end e a aplicação de conceitos de componentes e interfaces interativas. O desenvolvimento também se integra às práticas de versionamento e publicação estudadas durante a disciplina.

## Aula 09 - Projeto React 02

A aula dá sequência ao projeto React iniciado no bloco anterior. A atividade registrada é a aplicação de gestão de atividades identificada como um projeto que reúne 11 conceitos, com código versionado e publicação online.

O foco é consolidar a construção e evolução de uma aplicação React, mantendo o projeto organizado e funcional. O detalhamento dos 11 conceitos não está especificado no README consultado; por isso, este resumo não atribui nomes ou comportamentos específicos a eles.

## Síntese da disciplina

Ao longo das aulas, os conteúdos avançam dos fundamentos de HTML, CSS e JavaScript para o uso de frameworks, integração com APIs, criação de serviços e desenvolvimento de projetos React. Git e GitHub apoiam o versionamento e a colaboração, enquanto a Vercel e outras plataformas permitem publicar aplicações. As atividades práticas conectam essas ferramentas e conceitos em projetos front-end.
