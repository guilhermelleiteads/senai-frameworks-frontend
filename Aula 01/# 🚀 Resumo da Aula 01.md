# 🚀 Resumo Completo da Disciplina: Frameworks Front-end

## 📚 Apresentação da Disciplina

A disciplina **Frameworks Front-end** tem como objetivo preparar o estudante para desenvolver aplicações web modernas, responsivas e alinhadas às práticas utilizadas pelas empresas de tecnologia e pela indústria de software. O curso combina fundamentos teóricos e desenvolvimento prático, proporcionando uma visão ampla sobre a construção de interfaces modernas e escaláveis. 【1-24588d】【2-6919cb】

A unidade curricular possui carga horária total de **100 horas-aula (83h20 em hora-relógio)** e está inserida no módulo específico da formação profissional. 【1-24588d】

# 🌐 O que é Desenvolvimento Front-end?

O Front-end corresponde à camada da aplicação com a qual o usuário interage diretamente.

Ele é responsável por:

- 🎨 Interface visual
- 📱 Responsividade
- 🖱️ Interação do usuário
- 😊 Experiência do usuário (UX)
- 🔗 Comunicação com sistemas Back-end

Atualmente, praticamente todas as aplicações web modernas utilizam frameworks Front-end para criar interfaces mais rápidas, organizadas e fáceis de manter. 【2-6919cb】

---

# 🏗️ Contexto e Importância dos Frameworks

Os Frameworks Front-end surgiram para resolver problemas relacionados à complexidade crescente das aplicações web.

Entre seus benefícios estão:

- ⚡ Maior produtividade
- ♻️ Reutilização de código
- 📦 Componentização
- 🧩 Organização da aplicação
- 🔧 Facilidade de manutenção
- 📈 Escalabilidade

Os principais frameworks abordados e citados durante a disciplina são:

- ⚛️ React
- 🅰️ Angular
- 🟢 Vue.js

Essas ferramentas dominam o mercado atual de desenvolvimento web. 【2-6919cb】【1-24588d】
